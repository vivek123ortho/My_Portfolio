      Clarify SQL: Text-to-SQL Assistant with Clarification Engine

      Python · PostgreSQL · LangChain · Pydantic · sqlglot · Streamlit · Groq/Gemini

      • Built an LLM-powered text-to-SQL assistant that detects ambiguous questions (e.g., “top customer”) and asks schema-grounded multiple-choice clarifications instead of guessing, using Pydantic structured outputs and a swappable Groq/Gemini/OpenAI provider.
      • Raised correctness on a 17-case gold-SQL benchmark from 7/17 (no clarification) to 15-17/17 with the full detect, ask, and generate pipeline; ambiguity detection scored 19/20 on a labeled test set.
      • Designed three-layer query safety: sqlglot AST validation (single SELECT, blocked functions), a read-only PostgreSQL role, and a 5-second statement timeout, verified by 17 attack-style test cases.
      • Built an LLM-simulated-user evaluation harness, retry handling for malformed structured output, a Streamlit UI, and a GitHub Actions CI pipeline.
